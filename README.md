# Xhitter

Xhitter is the most modern 🚀🚀, profitable 📈📈, greatest 🔥🔥 website known to man 👨👨.

This project was made for a CS Ethics Course and is a social commentary on the Enshittification of
modern sites.

## Requirements

To get started with the repository, ensure the following dependencies are installed on your system:

- [Node.js](https://nodejs.org/en/download) (v24) - Javascript runtime
- [pnpm](https://pnpm.io/installation#using-corepack) - Package manager
